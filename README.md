# AI-Generated Image Detection

Deep learning-based detection of AI-generated images using ELA, CNN, EfficientNet-B4, and Grad-CAM.

## Project Overview

This project focuses on detecting whether an input image is AI-generated or human-created. The system uses deep learning models along with Error Level Analysis (ELA) preprocessing to identify patterns and artifacts associated with AI-generated images.

Grad-CAM is incorporated as an Explainable AI (XAI) technique to visualize the image regions that contribute to the model's prediction.

## Methodology

The major stages of the proposed system are:

1. Image input through the GUI.
2. Image preprocessing and resizing.
3. Error Level Analysis (ELA) for extracting compression-related features.
4. Classification using deep learning models.
5. Grad-CAM visualization for explaining model predictions.
6. Display of the prediction and explanation to the user.

## Models Used

### Hybrid CNN (RGB + ELA)
A CNN-based model that uses both the original RGB representation and ELA-based features to improve classification between AI-generated and human-created images.

### EfficientNet-B4
A transfer-learning-based image classification model used to evaluate the effectiveness of a deeper and more efficient CNN architecture for AI-generated image detection.

### Baseline CNN
A basic CNN model used as a reference to compare the performance improvement obtained through ELA preprocessing and the proposed approaches.

## Explainable AI

Grad-CAM (Gradient-weighted Class Activation Mapping) is used to generate visual heatmaps showing the regions of an image that contribute most to the model's prediction. This improves the interpretability of the detection system.

## Limitations

Performance may be affected by image compression, preprocessing, and variations in images generated by unseen AI models. Further evaluation on a wider range of generative models can improve the robustness of the system.
